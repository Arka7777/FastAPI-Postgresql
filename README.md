# Student Management API

A RESTful Student Management API built with **FastAPI, PostgreSQL, SQLAlchemy, and Docker**. This project demonstrates how to build backend APIs, manage relational database operations, validate request data, and containerize an application using Docker Compose.

## Live Demo : https://fastapi-postgresql-1.onrender.com/
## Features

- **FastAPI:** Build RESTful API endpoints.
- **PostgreSQL:** Store student records in a relational database.
- **SQLAlchemy ORM:** Interact with the database using Python objects.
- **Pydantic:** Validate incoming data and structure API responses.
- **CRUD Operations:** Manage student records through API endpoints as implemented.
- **Database Transactions:** Use commit, rollback, and refresh for reliable database operations.
- **Docker:** Containerize the FastAPI application.
- **Docker Compose:** Run the API and PostgreSQL database together.
